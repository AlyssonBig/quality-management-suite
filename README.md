 # Quality Management Suite

### Gestão da Qualidade Industrial | Python • HTML • Indicadores

Conjunto de dois protótipos de software desenvolvidos para explorar soluções digitais aplicadas à gestão da qualidade industrial, com foco em organização de registros, rastreabilidade, acompanhamento de não conformidades e análise de indicadores.

## Sobre o projeto

O Quality Management Suite reúne duas aplicações com tecnologias e propostas complementares.

O objetivo é demonstrar como ferramentas digitais podem contribuir para a padronização de processos, a centralização de informações e o apoio à tomada de decisões na área da Qualidade.

## 1. Aplicativo Desktop — Python

**Tecnologias:** Python, Kivy, OpenPyXL e Excel.

Aplicação desktop com interface gráfica desenvolvida para apoiar atividades operacionais da qualidade.

**Características:**
- Interface visual com módulos de registro e consulta.
- Organização de informações relacionadas aos processos da qualidade.
- Armazenamento local dos registros em planilha Excel.
- Estrutura voltada à utilização em computadores.

### Execução

Instale Python e execute os comandos na pasta do aplicativo:

```bash
pip install -r requirements.txt
python main.py
```

## 2. Aplicativo Web — HTML

**Tecnologias:** HTML, CSS e JavaScript.

Protótipo de consulta e acompanhamento de informações relacionadas à qualidade industrial.

**Características:**
- Histórico de não conformidades.
- Consulta de registros por identificação de itens.
- Acompanhamento de seleções e seus resultados.
- Visualização de registros relacionados a S.R.O.
- Indicadores gráficos para análise das ocorrências.
- Interface visual com informações e imagens demonstrativas.

### Execução

Abra o arquivo `index.html` da pasta do aplicativo HTML em um navegador compatível.

O repositório também contém arquivos auxiliares utilizados na demonstração.

## Objetivos do desenvolvimento

- Explorar oportunidades de digitalização na gestão da qualidade.
- Facilitar a consulta e a organização de informações.
- Demonstrar possibilidades de acompanhamento visual de indicadores.
- Aplicar conhecimentos de programação à melhoria contínua.
- Desenvolver soluções com foco na experiência do usuário.
