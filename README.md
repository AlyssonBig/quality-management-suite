# Quality Management Suite

Dois protótipos de apoio à gestão da qualidade industrial para uso em computador.

## Aplicativo Python

Interface Kivy com módulos de registro e consulta de processos da qualidade. Os registros são armazenados localmente em uma planilha Excel gerada pelo aplicativo.

```bash
cd python-app
pip install -r requirements.txt
python main.py
```

## Aplicativo HTML

Protótipo de histórico de não conformidades, seleções e indicadores. Abra `html-app/index.html` no navegador. O arquivo `banco_de_dados.csv` acompanha o exemplo original. Consulte `LEIA-ME-original.txt` para orientações do projeto.

## Observações

- Protótipos de demonstração; não representam implantação ou aprovação corporativa.
- As logomarcas visuais foram removidas das interfaces.
